🔧 Key Components

Model Class

• Manages products array (static data)
• Manages cart array (in memory only)
• Methods: addProductToCart(), bindCartChanged()
• No localStorage - data resets on page refresh

View Class

• Renders product cards
• Shows cart items
• Handles "Add to Cart" button clicks
• Methods: displayProducts(), displayCart(), bindAddToCart()

Controller Class

• Connects Model and View
• Handles add to cart events
• Updates view when cart changes
• Simple event flow management

📊 Simple Data Flow

1. User clicks "Add to Cart" button
2. Controller receives click event
3. Controller calls model.addProductToCart(id)
4. Model adds product to cart array (in memory)
5. Model notifies controller of change
6. Controller updates view to show new cart state

🚀 Usage

• Click "Adicionar ao Carrinho" on any product
• Cart updates immediately in the right panel
• Data is kept in memory only
• Refresh page = cart resets to empty
• No persistence, no complex state management
